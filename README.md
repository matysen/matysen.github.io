# Portfolio académique — Dre. Maty SENE

## Organisation
- `index.html` : accueil
- `pages/` : pages Profil, Recherche, Projets, Publications, Parcours, Enseignement, Mémoires encadrés, Galerie et Contact
- `css/style.css` : styles communs et menu déroulant
- `js/script.js` : menu mobile, sous-menus et sélecteur de langue français/anglais
- `images/` : portrait et photos de galerie à ajouter
- `documents/` : documents PDF éventuels

## Menu du site
- Accueil
- À propos : Profil, Parcours
- Recherche : Axes de recherche, Publications
- Activités : Projets, Enseignement, Mémoires encadrés
- Galerie
- Contact

## Bilingue
Le bouton FR/EN est présent sur chaque page. La traduction anglaise est intégrée localement dans `js/script.js` et le choix de langue est mémorisé dans le navigateur lors de la navigation entre les pages. Aucun service de traduction externe n'est nécessaire.
